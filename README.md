# JARVIS - Just A Rather Very Intelligent System

> A fully local AI assistant built from scratch.
> No pre-built LLMs. No APIs. Pure math and code.

---

## Vision
Build a JARVIS-like AI assistant that can:
- 🎙️ Hear your voice and recognize your identity
- 🧠 Think using a brain built entirely from scratch
- 🗣️ Speak back in its own voice
- 💻 Control your PC, browse the web, write code
- 🧠 Remember everything across sessions
- 🌍 Speak multiple languages
- 🔒 Obey only its owner

## Tech Stack
- **Language:** Python 3.13
- **Framework:** PyTorch (CPU) — math tool only
- **Tokenizer:** Custom BPE — built from scratch
- **Brain:** Custom Transformer — built from scratch
- **STT:** To be built from scratch
- **TTS:** To be built from scratch
- **Memory:** Custom vector DB — to be built from scratch
- **Tools:** pyautogui, psutil, playwright, subprocess

---

## Build Approach
- Everything from the deepest mathematical core
- No pre-built language models
- Plan thoroughly → build small → scale up
- One phase at a time, confirmed before proceeding
